# Next.js frontend

Repo: frontend/<app>/. `app/(auth)/login`, `app/(app)/layout.tsx` (shell, nav by privilege),
`app/(app)/<module>/{page.tsx,[id]/page.tsx,new/page.tsx}`, `components/{ui,forms,tables}`,
`lib/api/{client.ts,types.ts,<module>.ts}`, `lib/format/`, `lib/i18n/`, `lib/auth/`,
`messages/<locale>.json`, `tests/{unit,e2e}`.
- API client: fetch wrapper adds Bearer token, X-Company-Id, Accept-Language; maps error body to
  `ApiError{code,message,fields}`; types generated by hand from the contract DTO section.
- Server components for lists/detail reads; client components for forms; TanStack Query for
  caching and mutations; forms with react-hook-form + zod schemas mirroring contract rules.
- Dates: `<DateInput>` works in dd/mm/yyyy with a calendar; values sent as strings from
  `lib/format`. Money/qty inputs use `<DecimalInput kind="money">` with pack grouping on blur.
- i18n: next-intl; every string via `t()`; no hard-coded labels; RTL via `dir` on html.
- Privileges: `/me` loaded into a context; `<Can priv="x.y">` wrapper; route guard in layout.
- Lists: generic `<DataTable>` with cursor pagination, column config, totals row; reports use
  `<ReportPage code>`.
- Styling: Tailwind + shared design tokens from the product's design system (Figma/Claude Design
  spec referenced in the ticket); Genplus admin theme components where applicable.
- Tests: Vitest + Testing Library for components; Playwright for e2e.
Commands: `npm run dev`, `npm run lint`, `npx tsc --noEmit`, `npm test`, `npx playwright test`.
